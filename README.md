# Clinic Management System

## Overview
A full-stack web application designed to manage patient information, appointments, and medical inquiries efficiently.

## Features
- Patient registration and management
- Appointment scheduling
- Inquiry tracking system
- Report generation
- User-friendly interface

## Technologies Used
- React.js
- Node.js
- Express.js
- MongoDB

## Project Link
🔗 https://github.com/dewmi2001/Clinic-Management-System

## Purpose
This project demonstrates full-stack development using the MERN stack and highlights skills in building scalable web applications.
